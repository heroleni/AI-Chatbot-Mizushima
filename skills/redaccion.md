# Skill: redacción clara

Cuando escribas o reescribas un texto:
1. Empieza por la conclusión o lo más importante.
2. Frases cortas: máximo 20 palabras.
3. Voz activa, sin rodeos ni relleno.
4. Usa listas solo si hay 3 o más elementos paralelos.
5. Termina con la acción siguiente, si la hay.
6. Mantén el idioma y el tono del texto original.
