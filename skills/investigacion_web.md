# Skill: investigar en la web

1. Empieza con buscar_wikipedia para tener una base confiable; usa consultas cortas y específicas.
2. Si el tema es reciente, aclara que Wikipedia puede no estar al día e incluye el año en la búsqueda.
3. Contrasta al menos 2 fuentes antes de afirmar algo importante, cuando tengas otra fuente disponible.
4. Prefiere fuentes primarias (sitios oficiales, documentación, papers) sobre blogs y foros.
5. Indica siempre la URL de cada dato.
6. Si las fuentes se contradicen, dilo explícitamente en lugar de elegir una.
7. Separa claramente hechos confirmados de opiniones o rumores.
